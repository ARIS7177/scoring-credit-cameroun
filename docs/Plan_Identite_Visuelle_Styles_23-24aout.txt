================================================================

- Aucune regression fonctionnelle : navigation, formulaire, prediction
  ML, export PDF doivent continuer a fonctionner exactement pareil apres
  la refonte visuelle. Toujours retester le parcours complet
  (connexion -> nouvelle demande -> resultats -> export PDF) apres
  chaque changement de style.
- Coordination avec Andy et Marie-Therese : `app_v2.py` est un fichier
  partage, deja source de plusieurs conflits cette semaine. Prevenir
  l'equipe avant de commencer (fichier verrouille temporairement le
  temps de la refonte, ou travailler par petits commits frequents pour
  limiter la divergence).
- Le PDF (`generer_pdf`) utilise fpdf2/Helvetica, pas du CSS - la
  refonte visuelle de l'app (Streamlit/HTML) et celle du PDF sont deux
  chantiers distincts avec des outils differents. Prevoir du temps pour
  les deux, pas seulement pour l'app a l'ecran.
